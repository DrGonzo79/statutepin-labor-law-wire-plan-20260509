# Roadmap — Statutepin

## 0–30 days: Concierge MVP

- Recruit 10–15 HR generalists at 50–300 employee remote/hybrid companies.
- Cover 4–5 high-change states: CA, NY, WA, CO, IL.
- Build source registry and manual+LLM monitoring process.
- Ship Slack/email alerts from a lightweight admin dashboard.
- Create audit-log MVP: alert delivered, acknowledged, assigned, completed.
- Run weekly customer debriefs.
- Charge at least 3 pilots $299/month before automating deeply.

## 31–60 days: Productized trust loop

- Build reviewer console.
- Add structured alert schema and checklist templates.
- Add customer jurisdiction profiles and employee-count thresholds.
- Launch dashboard: red/yellow/green jurisdiction risk, upcoming effective dates, open tasks.
- Measure accuracy across 100 reviewed alerts.
- Publish state-specific compliance scare reports as GTM assets.

## 61–90 days: Integration and repeatability

- Add BambooHR import for employee locations.
- Add Slack OAuth and self-serve notification settings.
- Expand from 5 to 10 states for Pro customers.
- Build partner channel with payroll consultants and fractional HR firms.
- Introduce legal escalation workflow with outside counsel partner.
- Target 20 paying customers and $6K–$10K MRR.

## Later

- City/county ordinance coverage.
- Payroll-provider update recommendations.
- Policy document diff suggestions.
- Compliance evidence exports for audits.
- International modules for Canada/UK/EU only after US wedge is profitable.
